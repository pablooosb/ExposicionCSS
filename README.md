<h1 align="center">CAMBIO DE TEMA AUTOMÁTICO</h1>
El cambio de tema automático según cual tengas aplicado en tu equipo es muy sencillo de aplicar sin utilizar JavaScript. Tienes que llamar al <code>color-scheme: light dark</code>. Y una vez llamado, le asignas a cada cosa lo que quieras. Le puedes asignar un color al fondo, un color al texto, a lo que quieras. Simplemente cuando quieras aplicarlo, indicas a que lo quieres aplicar y llamas al <code>light-dark</code> y entre paréntesis le asignas dos colores separados por comas, el cual el primero es para el tema claro y el segundo para el tema oscuro.
Esto es muy útil si quieres utilizar un esquema de colores para el tema claro y otro para el oscuro, y no quieres añadir JavaScript a tu página web.

<h1 align="center">BORDES</h1>
A parte de todos los bordes que ya teníamos antes (solid, dashed, dotted, double, groove, ridge, inset y outset) ahora tenemos nuevos modelos.
Tenemos el borde con degradado, el cual conseguimos utilizando un <code>border-image</code> donde normalmente usaremos el linear-gradient junto a la dirección en el que queremos que vayan los colores y le pasaremos los colores necesarios para el degradado.
Por otro lado, tenemos el borde de cristal. Este funciona más o menos igual que el anterior, pero para que este se vea bien el borde, tenemos que llamar al <code>background</code> y asignarle con el linear-gradient para el fondo (que podemos dejarlo con un solo color asignandole el mismo color al degradado) y para el borde igual que el anterior, llamamos al linear-gradient, insertamos los colores y por último se lo asignamos al <code>border-box</code>.
También está el borde abstracto, el cual juega con los porcentajes del <code>border-radius</code> para hacer figuras únicas.
Y por último tenemos el borde animado. Como su nombre indica, este borde está en movimiento, también se le llama el borde de la serpiente, porque suele ser el movimiento como una serpiente. Este lo conseguimos mediante un <code>::before</code> junto con un <code>::after</code> y el @keyframes, donde le asignamos un from de donde quiere que empiece y un to en donde queremos que acabe.
De estos bordes nuevos, veo todos bastantes posibles de utilizar menos el abstracto, ya que no queda del todo profesional. El resto los podemos aplicar si queremos darle un estilo "mínimamente" colorido o por ejemplo el animado si le queremos dar énfasis a un recuadro concreto para que llame la atención.

<h1 align="center">COLORES</h1>
Para los colores, tenemos la posibilidad de hacer mezclas. Para realizar una, tenemos que asignarle el <code>color-mix</code> a lo que le queramos dar color, por ejemplo al fondo, y le asignamos un tipo de paleta (sRGB, OKLCH o HSL). La sRGB (Standard Red Green Blue) es la mezcla más utilizada, pero no permite una percepción visual óptima, ya que algunos colores más luminosos que otros aun teniendo el mismo valor de luminosidad. El OKLCH (OK Luminance, Chroma, Hue) es el "estándar moderno" y permite acceder a colores que los monitores antiguos no podían mostrar y garantiza que si cambias el tono, la sensación de brillo se mantenga. Y por último el HSL (Hue, Saturation, Lightness) es el que nos permite elegir el color en una rueda, para que sea más sencillo. Y también miente a la vista, ya que por ejemplo el azul al 50% de luminosidad es super oscuro, mientras que el amarillo con la misma luminosidad parece una bombilla, haciéndolo imposible para crear paletas de colores accesibles.
Esta nueva funcionalidad de CSS la veo un poco "atrasada" ya que teniendo la posibilidad de poder elegir todos los colores posibles, para que querríamos mezclarlos para obtener un resultado, cuando mediante un código lo conseguimos igual y más rápido.
